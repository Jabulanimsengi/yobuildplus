# Yobuildplus

A comprehensive builder and contractor directory application.

## Features
- **Frontend**: Next.js 14, Tailwind CSS, shadcn/ui.
- **Backend**: NestJS, Prisma, PostgreSQL.
- **Authentication**: JWT-based auth with secure password hashing.
- **Admin Dashboard**: Analytics, builder approvals, and content management.

## Getting Started

### Prerequisites
- Node.js
- PostgreSQL

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables in `.env` and `frontend/.env.local`.
3. Start the development servers:
   ```bash
   npm run dev
   ```
